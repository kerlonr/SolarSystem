## Sobre

Site educativo com duas páginas: uma sobre o **Sistema Solar** e seus oito planetas e outra
sobre **satélites**, naturais e artificiais, com imagens de cada um.

## Estrutura

```text
.
|-- index-planetas.html   o Sistema Solar e os planetas
|-- index-satelites.html  o que são satélites, naturais e artificiais
|-- style-planetas.css
|-- reset.css
`-- script.js
```

## Rodando Localmente

Projeto estático, sem dependências: abra o `index-planetas.html` no navegador.
